# PDF reading mode

Page zoom enlarges the fixed PDF page, so a line can run off the right edge of the phone. Reading mode extracts the text and shows it as wrapping paragraphs. A− and A+ change the font size, which is remembered on the device and shared with text letters, text activities, and text resources.

The control lives on the shared PDF viewer, so it opens for:

- a group resource whose type is `pdf`
- a journey activity whose type is `pdf`
- a library item whose media type is `pdf` (`midia_file_url`)

Page view stays available. A scanned PDF has no text layer, so reading mode explains that and the page view remains the way to see it. Images and the original page layout are not reproduced.
